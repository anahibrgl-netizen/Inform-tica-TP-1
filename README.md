## Descripción del Proyecto
Este proyecto explica cómo evolucionaron las herramientas de diseño gráfico en un período de cinco años (2021-2026) y cómo combinarlas junto con la inteligencia artificial, para crear una marca coherente y sostenible: evolución, matriz de herramientas, proceso en cinco etapas, kit de marca y buenas prácticas de IA.

---

## Estructura de los Archivos (Google Drive)

1. **`plan_web_marca.xlsx`: arquitectura de la página, componentes de interfaz, criterios de aceptación y SEO.
2. **`matriz_herramientas_marca.xlsx`: matriz de herramientas, contenido web y kit de marca.
3. **`analisis_herramientas_diseno_marca.docx`: análisis editorial de la evolución, las etapas del branding, los riesgos y las conclusiones.

## Herramientas Utilizadas y Metodología 

El desarrollo se realizó utilizando exclusivamente las herramientas autorizadas:

* **Perplexity AI:** Investigación y Recopilación de Herramientas de Diseño Gráfico para el desarrollo de una marca incorporando la IA.
* **Claude:** Evaluación de datos y consolidación del código base unificado (`index.html` CSS interno y Chart.js).
* **Netlify:** Plataforma de Infraestructura para publicar y actualizar la página web de forma automática y constante.
* **Gemini NotebookLM:** Integración de datos informativos del rol del diseñador con ia generativa para la estructuración del informe escrito.
* **GitHub:** Gestión de revisiones, documentación pública y clara en el archivo `README.md` y repositorio del codigo fuente.
