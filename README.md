# Inform-tica-TP-1
Este proyecto es una página web informativa que explica cómo evolucionaron las herramientas de diseño gráfico en un período de cinco años (2021-2026) y cómo combinarlas, junto con la inteligencia artificial, para crear una marca coherente y sostenible:evolución, matriz de herramientas, proceso en cinco etapas, kit de marca y buenas prácticas de IA.
